# Game Spec - Maputo Life

Title: Maputo Life (TBD final name)
Genre: Life sim (Sims-lite), browser-based
Platform: Web (Next.js)
Perspective: Top-down/Isometric-lite
Vibe: Chaotic, nostalgic
Players: Single-player (now)

## Core Features
- Avatar creation/customization (minimal)
- Movement between locations
- Location-based interactions
- HUD: location, time of day, simple stats
- Chapas, taxis, motos flavor
- Maputo iconography

## Locations
- Baixa (downtown)
- Praca da Independencia + Cathedral
- Mercado Central
- Railway Station
- Tunduru Gardens
- Fortaleza
- Costa do Sol
- FEIMA
- Polana/Sommerschield

## UI/UX (LagosLife style)
- Warm, slightly nostalgic
- Clean HUD
- Simple menus

## Technical
- Next.js 15+ (App Router), TypeScript, Tailwind
- Client-side game logic (Canvas or React DOM)
- JSON data for locations/dialogue
- Static assets
